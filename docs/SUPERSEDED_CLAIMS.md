## How to read this file

- **Labels.** **VERIFIED**: reproduced by an independent code path or a re-run, or re-checked against a committed file. **MEASURED**: one recorded run, not independently repeated. **INFERENCE**: an interpretation. Text in quotation marks is copied from the cited line (wrapped lines joined, Markdown bold markers dropped); it is VERIFIED as what the record says by reading that line. A number inside a quote is the number the record gives, not a new measurement.
- **Citations.** `file:line` links to the line at a fixed commit; the `@hash` after it is the oldest commit that introduced that text. `RULES.md` lines 1–3202, all of `LEDGER.md` and `CHANGELOG.md` lines 1–422 are identical at `71720ce` and now. `STATE.md` gained a 37-line release section at its top in [`commit 5cf8976`](https://github.com/abundantjoe/hercules/commit/5cf8976), with no old line changed or removed, so an old `STATE.md` line cited here sits 37 lines lower at the release head (`STATE.md:171` is now line 208) — VERIFIED (git diff). All four files link to `71720ce`, where the cited line numbers hold. Text added on 2026-10-15 links to the commit that added it, or, for a file regenerated later that day, to its latest version. A quote that wraps is cited at its first line.
- **Kinds.** WITHDRAWN: retracted. CORRECTED: a wrong number, count or status replaced by a right one. VOID: a verdict or arm annulled because its input was defective. NARROWED: survives in a weaker or more specific form. REFUTED: a premise, prediction or hypothesis contradicted by measurement or by external fact. ERRATUM: a recording error found at release (section B); E1–E18 and E21 are corrected by no notebook entry, E19 was corrected by an appended notebook line, E20 in code and E22 by a section appended to its record.
- **Order.** Item 1 is the most consequential; items 1b–1d are the narrowings that its replacement test, R-HELDOUT, added on 2026-10-15. Items 2–43 follow roughly newest first, each placed by the git time of its main correction commit. Items corrected over several commits overlap their neighbours: item 7's last correction ([`commit 7fdf466`](https://github.com/abundantjoe/hercules/commit/7fdf466), 10:15:13 UTC) is 90 seconds newer than item 6's last ([`commit d29112c`](https://github.com/abundantjoe/hercules/commit/d29112c), 10:13:43 UTC), and item 12's last step (G-OWN, `d29112c`) is newer than item 11 — VERIFIED (git log).
- **Times.** Times inside quotes are the notebook's own labels. Some differ from git commit times; from the entry "R-SYM declared" onward the labels run about two hours fast [`RULES.md:1737`](https://github.com/abundantjoe/hercules/blob/71720ce/RULES.md?plain=1#L1737) `@2d9e698` ([item 19](#item-19)), and the 2026-10-15 correction of R-HELDOUT is labelled ten minutes after its commit ([E19](#e19)). Where they disagree, git order decides what came first.
- **Unlabelled sentences.** Summary cells paraphrase the quotes in the item sections, with numbers copied exactly. A sentence with no label of its own that interprets a quote (most "What depended on it" lines) is INFERENCE.
- **Who caught it.** Every notebook entry is written in the first person by one author. The last column of the summary says how each error surfaced.
