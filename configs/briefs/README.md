# configs/briefs

Provenance: Project HERCULES | owner the owner | [id removed]

Hashed brief templates. `reader_P.txt` is the section 5.10 reader prompt P verbatim
(placeholders in braces; doubled braces are literal JSON braces). It is frozen and
hashed in METHOD.md only after READ-CAL; any change is a new declaration.
`harness_wrapper.txt` wraps every picker/sealer/reader brief with the tool restriction
checked afterwards by `hercules.harness.audit`.
The template files carry no provenance line because their bytes are sent to blind
readers verbatim; this README carries it.
