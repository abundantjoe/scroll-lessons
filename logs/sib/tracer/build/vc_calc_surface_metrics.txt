Calculate surface metrics based on a point collection.:
  -h [ --help ]         Print help
  --collection arg      Input point collection file (.json)
  --surface arg         Input surface file (.tif)
  --winding arg         Input winding file (.tif)
  --output arg          Output metrics file (.json)
  --z_min arg (=-1)     Minimum slice index to consider (optional)
  --z_max arg (=-1)     Maximum slice index to consider (optional)
